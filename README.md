# Zero-Doraemon 🛎️

`zero-doraemon` 是一个专为 `go-zero` 框架打造的基础工具箱和通用组件库。

在开发 `go-zero` 微服务或 Web 项目时，本项目提供了一系列开箱即用的、与具体业务无关的通用能力，旨在避免重复造轮子，并统一项目的基础规范（如错误码、响应格式、参数校验等）。就如同哆啦A梦的百宝袋一样，随取随用。

## 📦 核心模块

项目主要包含以下几个核心模块：

- 🛠️ **`coreKit` (核心组件)**：专为 `go-zero` 设计的通用功能集合。包含标准 HTTP 响应、REST 错误处理（401/404/405 等）、环境与上下文处理、JWT 鉴权等。
- 🔧 **`helpers` (通用工具)**：完全与框架无关的纯 Go 基础工具方法。包含数组/切片处理、文件操作、全局唯一 ID 生成（雪花算法）、客户端 IP 获取等。
- ⚠️ **`errcode` (错误码管理)**：提供了一套标准的错误定义和管理机制。支持全局唯一错误码、格式化错误提示、追加详细错误信息以及包裹原始错误。
- ✅ **`validator` (参数校验)**：基于 `govalidator` 进行二次封装。提供便捷的结构体和 HTTP 请求参数校验，并内置了针对中文字符长度（`min_cn`, `max_cn`）和数字大小（`number_min`, `number_max`）等自定义规则。
- 📄 **`paginator` (分页器)**：通用的分页逻辑处理工具。

## 🚀 安装

```bash
go get github.com/pudongping/zero-doraemon
```

> **⚠️ 注意：注意：本项目依赖 Go 1.25+ 及 go-zero 框架**
